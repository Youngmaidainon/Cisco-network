## 🟢 Level 1: SOHO Network (Small Office / Home Office)

### 🎯 จุดประสงค์ของโปรเจกต์
* เพื่อจำลองสถาปัตยกรรมระบบเครือข่ายระดับเริ่มต้นสำหรับธุรกิจขนาดเล็ก Startup หรือ Co-working Space ที่มีพนักงานจำนวนไม่เกิน 20 คน
* มุ่งเน้นการจัดการระบบเครือข่ายให้พนักงานสามารถเข้าใช้งานอินเทอร์เน็ตได้อย่างปลอดภัยทั้งรูปแบบสาย LAN และคลื่นสัญญาณไร้สาย (Wi-Fi)
* ฝึกฝนการเปิดใช้งานบริการแจกจ่ายไอพีอัตโนมัติ (DHCP Server) เพื่อลดความซ้ำซ้อนและภาระงานของผู้ดูแลระบบในการตามแก้ไขไอพีทีละอุปกรณ์
* ประยุกต์ใช้งานเทคโนโลยี NAT (Network Address Translation) รูปแบบ Overload (PAT) เพื่อแปลง Private IP ภายในองค์กรให้ใช้งาน Public IP เดียวกันออกสู่อินเทอร์เน็ตได้อย่างคุ้มค่า

### 🔬 เกณฑ์และวิธีการทดสอบระบบ (Verification Checklist)
* **การทดสอบระบบ DHCP:** * เปิดพอร์ตคอมพิวเตอร์ `PC-Admin` เปลี่ยนโหมดเป็น DHCP อุปกรณ์ต้องได้รับ IP Address ในวง `192.168.1.0/24` พร้อม Gateway (`192.168.1.1`) และ DNS Server (`8.8.8.8`) ครบถ้วนโดยไม่มีค่าว่าง
* **การทดสอบระบบเชื่อมต่อ Wi-Fi:** * อุปกรณ์ `Laptop-Wireless` ต้องสามารถเชื่อมต่อสัญญาณ (Link Link) กับ `Wi-Fi-Router` และได้รับ IP Address วงภายในอย่างถูกต้อง
* **การทดสอบการเชื่อมต่อปลายทาง (End-to-End Connectivity):** * เปิดหน้าต่าง Command Prompt บน `PC-Admin` พิมพ์คำสั่ง `ping 8.8.8.8` (เซิร์ฟเวอร์อินเทอร์เน็ตจำลอง) ระบบต้องตอบกลับเป็น *Reply from 8.8.8.8* ทั้งหมด 4 บรรทัด
* **การตรวจสอบตาราง NAT บนเราเตอร์:** * เข้าหน้าจอ CLI ของ `R1-SOHO` พิมพ์คำสั่ง `show ip nat translations` ระบบต้องแสดงตารางการจับคู่ระหว่าง Inside Global (Public IP) และ Inside Local (Private IP) ในขณะที่คอมพิวเตอร์กำลังรับส่งข้อมูลออกสู่ภายนอก
